# Construcciones Elif García

Sitio estático de presentación de la constructora. Para comenzar, abre `index.html`; sin una sesión activa, el sitio te enviará al formulario de acceso.

## Acceso de demostración

- Usuario: `user`
- Contraseña: `123`

La sesión se conserva en `sessionStorage` durante la pestaña actual. El enlace **Cerrar sesión** termina la sesión y vuelve al formulario.

Este acceso solo simula una autenticación en el navegador. Las credenciales están visibles en los archivos del sitio y no deben usarse para proteger información real. Para producción se necesita autenticación del lado del servidor.

## Páginas

- `index.html`: inicio y servicios.
- `about.html`: información de la empresa.
- `projects.html`: galería de proyectos.
- `contact.html`: formulario de contacto de demostración.
- `login.html`: acceso de demostración.
